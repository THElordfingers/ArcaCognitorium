## I. SESSION OVERVIEW

The Convocatio Iudicii convened to receive, dissect, cross-examine, and
deliver findings on the design revision packages submitted by the three
bureaus of the Triumviratus Aestheticus Imperialis. All three packages
were examined individually, then cross-examined as a collegiate body.

The panel comprised nine seated members drawn from the Council roster,
three Bureau representatives attending as presenting parties, the Wizard
presiding, and The Builder observing in silence.

The session produced conditional approvals for all three bureaus. No
package was rejected. No package was approved without condition. Each
bureau must submit a v1.1 package addressing the amendments listed in
this document. The Seal is held until v1.1 is received and confirmed.

### Shell Rulings

The Titulum shares the top band with the Fascia. The Titulum occupies
the top-left block. The Fascia occupies the top-right strip only. The
Titulum does not span the full top width.

The Feature Codex begins below the Titulum's lower boundary at the left
rail and runs full remaining height.

The Feature Menu switches are instant stack swaps. No animation.

The LAT/EN language toggle is placed in the Titulum pane across all
three bureaus. It is a persistent preference, not a feature action.
This applies to all three bureaus without exception.

The HELP button is always the rightmost element of the Fascia. It is
the only persistent Fascia element. All other Fascia buttons are
feature-specific.

The following decisions were ratified by the Wizard during the session
and are binding on all three bureaus effective immediately.

│  prior to submission. No content has been invented where            │
│  canonical content exists.                                          │
│                                                                     │
│  Bureau: ___________________                                        │
│  Version: __________________                                        │
│  Date: _____________________                                        │
╰─────────────────────────────────────────────────────────────────────╯

### Opening Ceremony

Each bureau is required to submit, alongside their v1.1 package, a
proposed Opening Ceremony for their respective application. This
submission is non-ratifiable and carries no review criteria. It is
left entirely to each bureau's imagination. There are no constraints.

### Wireframe Format

The HTML wireframe format presented in this session is ratified as the
new standard for all wireframes produced hereafter. The ASCII wireframe
format is retired for formal submissions. A dedicated session will be
scheduled to update the infrastructure documentation standards.

### Dirty State Marker

The asterisk (*) is retired as the dirty state indicator across all
bureau applications. The Aesthete will propose alternatives in the
v1.1 package review. The replacement will be ratified by the Wizard
at that time.
