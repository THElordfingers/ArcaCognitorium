# Wizard Document Style Guide

When generating .wiz documents (renamed .docx files) for this user, apply the following style spec without being asked.

---

## Fonts

- **Body text:** `Latin Modern Roman`
- **All headings and titles:** `Ebon Sigil`

---

## Colours

Documents are read on a dark background. All colours are chosen for legibility on black.

| Element | Colour |
|---|---|
| Body text | `#BDAB5D` — warm gold |
| H1 | `#E8C96A` — bright arcane gold |
| H2 | `#7EC8C8` — arcane teal |
| H3 | `#A98FD4` — wizard violet |
| H4 | `#C87941` — ember orange |
| H5 | `#8FAD8F` — silver-green |
| H6 | `#8C7B5C` — dim parchment |
| Title | `#E8C96A` — bright arcane gold |
| Hyperlinks | `#7EC8C8` |
| Code block background | `#1A1040` — deep amethyst |
| Table header fill | `#2A1A4A` — dark purple |
| Table header text | `#E8C96A` |
| Table cell borders | `#6B4E8A` — dark amethyst |
| Table header borders | `#8B6914` — dark gold |
| Bullet points | `#BDAB5D` |

## Document Rules

- Tables must never split across pages — apply `cantSplit` to all rows
- Output file extension is `.wiz` not `.docx`
- Do not change filenames when returning restyled documents
