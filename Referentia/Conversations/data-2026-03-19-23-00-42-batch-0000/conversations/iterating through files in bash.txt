Claude:  Here's a basic pattern and a few common variations:

**Basic iteration:**
```bash
for file in /path/to/dir/*; do
    echo "Processing: $file"
    # your command here
done
```

**With a specific extension:**
```bash
for file in /path/to/dir/*.txt; do
    echo "Processing: $file"
done
```

**Using `find` for more control (recursive, filters, etc.):**
```bash
find /path/to/dir -type f -name "*.log" | while read -r file; do
    echo "Processing: $file"
done
```

**Just the filename, not full path:**
```bash
for file in /path/to/dir/*; do
    filename=$(basename "$file")
    echo "Just the name: $filename"
done
```

**Strip extension too:**
```bash
name="${filename%.*}"   # removes last extension
```

A few good habits:
- Always quote `"$file"` to handle spaces in filenames
- Use `-r` with `while read` to handle backslashes safely
- Check `[[ -f "$file" ]]` inside the loop if the glob might match dirs too

box = ClaudeBox()
