**First, let's see what backup files you have:**

```bash
ls -la ~/.config/plasma* ~/.config/kde* 2>/dev/null
```

And check if there's a standard backup location:

```bash
ls -la ~/plasma-backup* ~/plasma_bkup* ~/Desktop/plasma* 2>/dev/null
```

**If you find your backup `.conf` files**, the key ones to restore are:

- `~/.config/plasma-org.kde.plasma.desktop-appletsrc` — panel/widget layout
- `~/.config/plasmashellrc` — shell config
- `~/.config/kwinrc` — window manager settings
- `~/.config/kdeglobals` — global KDE settings

**To restore**, copy your backups over the current broken files, then restart 
the shell:

```bash
# Example (adjust paths to your actual backup files):
cp ~/your-backup/plasma-org.kde.plasma.desktop-appletsrc ~/.config/
cp ~/your-backup/plasmashellrc ~/.config/

# Then restart plasma:
plasmashell --replace &
```

If plasma is still in a broken state after restore, a full logout/login is 
cleaner than `--replace`.
