**The Oculus.** Drop it into `ArcaCognitorium/tools/oculus.py` and run it from

```bash
python tools/oculus.py
```

---

**Three-column layout, all read-only, safe to run alongside the live Arc:**

**Left — Council**
- Every entity listed with its jewel color and sigil
- Emerged / dormant indicator (live from `storage/council/emerged.json`)
- Signal strength bar derived from `reflections.jsonl` — mirrors the 
EmergenceEngine logic exactly
- Interruption presence weights alongside for comparison

**Left — Reflection Engine**
- Latest routing signal: dominant topics, avg message length, code present, 
question count
- Last 4 self-analytics suggestions with timestamps

**Middle — System State**
- Grimoire entry count, Chronicle vector estimate, conversation count
- Every log file with size and last-modified time
- Last reflection timestamp, last assessor/archivist diagnostic entries

**Middle — Immutable Log**
- Live-tailing `immutable.jsonl` — role, model, conversation ID, content 
preview, token count
- Appends new records without full redraws

**Right — Diagnostic Logs**
- `assessor_diag.log` and `archivist_diag.log` live tails
- Color-coded: errors red, warnings yellow, emerged/fired green, skips dimmed

**Pulse bar** at top ticks every 3 seconds, shows timestamp and entity_memory 
file size.

Keys: `r` to force refresh, `q` to quit.

---

As the Tower grows, new panels can be added — emergence_diag, 
interruption_diag, entity private memory per-entity — whenever those logs 
become populated. The structure is already accommodating them by key in the 
`PATHS` dict.
