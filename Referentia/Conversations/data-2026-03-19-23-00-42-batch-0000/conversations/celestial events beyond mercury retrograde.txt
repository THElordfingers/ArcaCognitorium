- Retrograde status for any planet
- Eclipse calculations

- Planetary rise/set times
- Nakshatra positions

LordFingers: where does machina meteorology,get its local weather info

Claude:  From your `lat` and `lon` coordinates that you pass in at instantiation:

```python
wx = MachinaMeteorologica(lat=48.4, lon=-123.3)
```

Those coordinates get embedded into the Open-Meteo API request URL:

```
https://api.open-meteo.com/v1/forecast?latitude=48.4&longitude=-123.3&current=..
.
```

Open-Meteo looks up the nearest weather station to those coordinates and 
returns current conditions for that location. So the accuracy is only as good 
as the coordinates you give it — the closer to your actual location the 
better.

You'll want to set your actual coordinates. Victoria BC centre is roughly 
`lat=48.4278, lon=-123.3656`. Or get your precise coordinates from Google Maps 
— right-click anywhere and the coordinates appear at the top of the context 
menu.
