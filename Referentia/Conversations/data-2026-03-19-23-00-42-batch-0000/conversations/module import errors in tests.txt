**3. `test_cycle_raises_cycle_error` — cycle detection not raising 
`CycleError`**

Your topological sort isn't detecting cycles and raising the exception. This is 
a logic bug in `core/exporter.py`. A standard Kahn's algorithm fix — if after 
processing, any nodes remain with non-zero in-degree, there's a cycle:

```python
def _topological_sort(self, nodes, connections):
    from collections import deque

    node_ids = [n["node_id"] for n in nodes]  # use node_id, not id
    in_degree = {nid: 0 for nid in node_ids}
    graph = {nid: [] for nid in node_ids}

    for conn in connections:
        graph[conn["from_node"]].append(conn["to_node"])
        in_degree[conn["to_node"]] += 1

    queue = deque(nid for nid in node_ids if in_degree[nid] == 0)
    sorted_ids = []

    while queue:
        nid = queue.popleft()
        sorted_ids.append(nid)
        for neighbour in graph[nid]:
            in_degree[neighbour] -= 1
            if in_degree[neighbour] == 0:
                queue.append(neighbour)

    if len(sorted_ids) != len(node_ids):
        raise CycleError("Pipeline contains a cycle — export aborted.")

    return sorted_ids
```

class SnippetListWidget(QListWidget):
    """QListWidget subclass that initiates MIME drags with snippet_id data."""

    def mouseMoveEvent(self, event):
