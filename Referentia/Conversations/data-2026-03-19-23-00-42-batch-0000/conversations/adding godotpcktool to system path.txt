LordFingers: I have been using godotpcktool, but i have to run it from the directory it's 
in, how can i change it so i just have to type godotpcktool instead of 
/home/lordfingers/Importo/Godot/GodotPckTool-master/build/src/godotpcktool

Claude:  You need to add the godotpcktool directory to your system's PATH, or create a 
symlink to it in a directory that's already in your PATH. Here are a few ways 
to do this:

## Option 1: Create a symlink (easiest)

```bash
sudo ln -s 
/home/lordfingers/Importo/Godot/GodotPckTool-master/build/src/godotpcktool 
/usr/local/bin/godotpcktool
```

This creates a symbolic link in `/usr/local/bin`, which is typically in your 
PATH by default.

## Option 2: Add to your PATH permanently

Add the directory to your PATH by editing your shell configuration file:

```bash
echo 'export 
PATH="$PATH:/home/lordfingers/Importo/Godot/GodotPckTool-master/build/src"' >> 
~/.bashrc
```

Then reload your configuration:

```bash
source ~/.bashrc
```

If you're using zsh instead of bash, replace `.bashrc` with `.zshrc`.

## Option 3: Move it to a bin directory

If you have a personal bin directory:

```bash
mkdir -p ~/bin
cp /home/lordfingers/Importo/Godot/GodotPckTool-master/build/src/godotpcktool 
~/bin/
```

Then ensure `~/bin` is in your PATH (many distributions add this automatically).

I'd recommend **Option 1** (the symlink) as it's clean, doesn't require 
modifying your PATH, and the tool stays in its original location. After running 
that command, you should be able to just type `godotpcktool` from anywhere.
