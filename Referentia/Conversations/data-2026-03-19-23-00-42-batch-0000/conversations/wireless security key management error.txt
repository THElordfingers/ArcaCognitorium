LordFingers: Error: 802-11-wireless-security.key-mgmt: property is missing.

Claude:  This error indicates that your wireless network configuration is missing the 
`key-mgmt` (key management) property, which specifies the 
security/authentication method for the WiFi connection.

To fix this, you need to add the `key-mgmt` property to your network 
configuration. The value depends on your network's security type:

**Common values:**
- `wpa-psk` - For WPA/WPA2 Personal (most home networks)
- `wpa-eap` - For WPA/WPA2 Enterprise (corporate networks)
- `none` - For open/unsecured networks
- `sae` - For WPA3

**If using NetworkManager (nmcli):**
```bash
nmcli connection modify <connection-name> 802-11-wireless-security.key-mgmt 
wpa-psk
```

**If editing configuration file directly** (e.g., 
`/etc/NetworkManager/system-connections/`):
```ini
[802-11-wireless-security]
key-mgmt=wpa-psk
psk=your_wifi_password
```

**If using `nmtui`** (text UI):
1. Run `nmtui`
2. Select "Edit a connection"
3. Choose your WiFi connection
4. Under WiFi security, select the appropriate security type (this sets 
key-mgmt automatically)
