    OKLAB Integration: All color math (averaging, contrast, and scaling) now uses the 
    OKLAB perceptual color space.

    Tertiary Logic: Three modes: Complementary (of BG), Average (BG + FG via OKLAB), 
    and Manual.

    Sequential Hierarchy: UI logic enforces a 24pt/18pt/12pt font and size hierarchy 
    for Background, Foreground, and Tertiary elements.

    Algorithm Thresholds: Dedicated tab for algorithm selection (Linear/Step) with 
    dynamic info displays on recommended contrast levels.

    The "Stretchy" Canvas: Main display widget uses a Canvas that recalculates blob 
    sizes and font scales dynamically on window resize.

    Tabbed Sidebar: A CTkScrollableFrame housing a CTkTabview to categorize Sliders 
    (Algorithms, BG, FG, Tertiary, Help).

    Keyboard Navigation: * Tab: Cycle Main Pages.

        Shift + Tab: Cycle Sidebar Tabs.

        Ctrl + Tab: Cycle Sub-tabs (Help/Stats).

        Space: Generate Pair | Shift + Space: Randomize Sample Text.

    Focus Locking: All sliders and buttons are removed from the standard "tab-focus" 
    loop to ensure Tab only navigates pages.

    Slider Presets: Independent .json saving/loading for generator states (separate

    Multi-Tier Help: A nested help system including a "Suggestions" tab for color
